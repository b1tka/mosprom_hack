# Необязательные файлы-вложения сценария

Сценарий (`bot/src/scenario/scenario.yaml`) умеет прикладывать к сообщениям файлы, которых нет в ТЗ (PDF, презентации, открытки).
Положите файл сюда — бот начнёт отправлять его вместе с сообщением (после `docker compose up -d --build bot`). Нет файла — сообщение уходит без вложения.

Имя файла: `<слот>.<расширение>` для всех или `<слот>.<тег>.<расширение>` для конкретного тега (GTP, GrPP, Luzhniki), например `lunch.GTP.pdf`.

| Слот | Где используется |
|---|---|
| `lunch` | «Где пообедать» (первый день, команда /Food): PDF со списком заведений, можно свой на каждый тег |
| `map_territory` | карта территории (GTP, ответ «Да» в 11:00 первого дня) |
| `map_floors` | карта этажей (Luzhniki) |
| `presentation` | презентация «Ты – часть большой команды» (первый день, 15:00) |
| `adaptation_plan` | адаптационный план (3-й рабочий день, офис) |
| `card1`, `card2`, `card_hello`, `card_bye` | открытки |
| `events` | фото с корпоративных мероприятий (через 10 дней) |
| `quote` | изображение с цитатой («Финишная прямая») |
